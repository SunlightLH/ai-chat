# AI Chat 聊天助手

一个基于 React 构建的现代化 AI 聊天助手应用。

## 功能特点

- 💬 实时对话交互
- 🎨 现代化的 UI 设计
- 📱 响应式布局
- 🚀 快速响应
- 💾 对话历史记录

## 技术栈

- React 18
- React Hooks
- CSS3
- JavaScript ES6+

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm start
```

应用将在 [http://localhost:3000](http://localhost:3000) 打开。

### 构建生产版本

```bash
npm run build
```

构建后的文件将生成在 `build` 目录中。

## 使用说明

1. 在输入框中输入你的消息
2. 点击发送按钮或按下回车键
3. AI 助手会自动回复你的消息
